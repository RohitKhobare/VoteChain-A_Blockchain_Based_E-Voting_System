# Existing Technology Stack

This document records the stack declared in the project manifests and configuration; it does not prescribe a target stack.

## Languages and runtimes

- **Solidity:** compiler configured as `0.8.20` in `hardhat.config.js`; contract pragma is `^0.8.20`.
- **JavaScript / JSX:** CommonJS for Hardhat config, deployment, and tests; ES modules and JSX for the frontend.
- **Node.js/npm:** package manifests do not declare an `engines` range. Node.js 18+ is recommended; the installed dependency tree includes packages requiring Node.js 18 or newer.
- No TypeScript compiler configuration or separate backend runtime is present.

## Framework and runtime configuration

- Hardhat loads `@nomicfoundation/hardhat-toolbox` from `hardhat.config.js`.
- Solidity is configured at version `0.8.20`.
- Hardhat's local network and configured `localhost` network both use chain ID `31337`; localhost RPC is `http://127.0.0.1:8545`.
- Vite loads `@vitejs/plugin-react` and uses port `5173`.
- The React browser application uses `ethers.BrowserProvider` with the injected `window.ethereum` wallet provider.
- `frontend/src/contract.json` is generated by deployment and provides the ABI, address, and chain ID used by the browser app.
- The HTML document loads Space Grotesk from Google Fonts.

## Build and verification commands

Root scripts provide `compile`, `test`, `node`, and `deploy`; frontend scripts provide `dev`, `build`, and `preview`. The `frontend:install`, `frontend:dev`, and `frontend:build` root scripts forward commands to the frontend directory.

No evidence of IPFS, AES-256 encryption, SHA-256 application logic, database/ORM, or server-side HTTP framework appears in the source files inspected.
